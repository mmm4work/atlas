# Relation Lab — демо-страница

Лаборатория отношений. Исследуем себя. Понимаем друг друга. Создаём вместе.

Одностраничное демо: 3D-сцена (Three.js) проходит лестницу «я → ты → мы →
наша совместная жизнь» при прокрутке (GSAP ScrollTrigger). Без сборки:
откройте `index.html` в браузере или включите GitHub Pages для этой ветки.
